## 1. 이 프로젝트는 무엇인가

`C:\proj2_\study` — 리눅스마스터2급(추후 다른 자격증도 추가 가능) 공부 내용을 정리하고, 직접 만든 연습문제로 반복 학습할 수 있는 개인용 React(Vite) 웹앱. 목차 → 시험 → 과목 → 유형 4단계로 개념을 정리하고, 어느 단계에서든 "예제 문제 풀어보기"로 관련 문제를 바로 풀 수 있다.

현재 보유 연습문제 총합: **2차 455문항**(기본 73 + 추가 382) + **1차 341문항**(전부 유형별 기본 문제) = **796문항**.

**1차 시험의 남은 제한**: 통계(`stats/`)·실제 기출 원문(`realexams*/`)은 여전히 없다(1차 족보 PDF가 공식 회차 구분이 없는 비공식 컴필레이션이라 회차별 집계가 불가능하기 때문 — §4 참고). 그래서 과목/유형 카드의 출제 비율은 항상 0%로 표시되고, "실제 기출 다시 풀기" 버튼은 계속 숨겨져 있다. 다만 유형별 `questions/`가 전부 채워지면서 **가상 모의고사의 3가지 모드가 모두 정상 동작**하게 됨(이전에는 "풀고 채점하기"/"해설을 보면서 풀기"가 빈 화면이었음).

**과목(subject) 단위 개념 설명 — 2026-07-29 추가**: `content/.../<subjectId>/_meta.json`은 topic과 동일한 형태의 `concepts`(문자열 또는 `ContentBlocks` 배열 목록) / `example`(터미널 HTML) 필드를 지원한다(`loader.js`의 `ensureSubject`/`buildTree()`가 파싱해 `subject.concepts`/`subject.example`로 노출). `SubjectPage.jsx`가 이 값이 있을 때만 "과목 개요"/"실행 예제" 섹션을 SideNav 아래·QuizPanel 위에 렌더링한다. 1차의 두 과목에 각각 11개/8개 개념 불릿 + 예제 터미널을 채워 넣어, 유형 카드 목록 위에서 과목 전체 개요를 먼저 보여준다(유형별로도 별도 개념 설명이 있으니 이건 그 요약 격).

**1차 족보 PDF 파싱 관련 유의사항(2026-07-29)**: 75페이지 전체를 파싱해보니 여러 다른 출처가 짜깁기된 문서라 형식이 균일하지 않았다 — 문항 없이 순수 명령어 사전 역할만 하는 페이지(약 28~35쪽)는 문제로 취급하지 않고 제외했고, 일부 페이지는 문항 사이 줄 간격이 넓어서 파서가 보기 하나하나를 별개 문항으로 잘못 쪼개는 버그가 있어 수정했다(번호로 시작한 블록은 내부 줄 간격과 무관하게 다음 번호 전까지 통째로 묶도록 변경). 자세한 파싱 스크립트와 겪은 문제들은 메모리([[project-study-hub]])에 정리해 둠.

## 3. 화면/기능별 구현 현황

### 목차 · 시험 · 과목 · 유형 (HomePage / ExamPage / SubjectPage / TopicPage)
- 4단계 카드 네비게이션, 통계 바(출제비율 %는 `stats/` 실측치로 매번 계산).
- **카드에 "예제 N문항" 표시(2026-07-29 추가)**: `Card.jsx`가 `exampleCount` prop을 받으면 통계 줄 아래에 "예제 N문항"을 한 줄 더 보여준다. 시험 카드(HomePage)는 `getQuestionsByExam + getExtraQuestionsByExam`, 과목 카드(ExamPage)는 `getQuestionsBySubject + getExtraQuestionsBySubject`, 유형 카드(SubjectPage)는 `getQuestionsByTopic`(유형엔 extra 문제가 안 묶이므로 이것만)의 합으로 계산한다. `stats/`가 없어 출제비율이 항상 0%로 보이는 1차 시험에서도, 실제로 풀 수 있는 문제 수가 몇 개인지 바로 보이게 하는 게 목적.
- 각 단계에서 "예제 문제 풀어보기" 버튼 → 같은 화면 아래로 QuizPanel이 펼쳐짐. TopicPage는 이전/다음 항목(SideNav)이 QuizPanel **아래**에 오도록 배치(SubjectPage는 아직 위에 있음 — 필요시 동일하게 변경 가능).
  - 버튼 라벨에도 문항수가 붙는다: "예제 문제 풀어보기(N문항)" — 4단계 전부(HomePage/ExamPage/SubjectPage/TopicPage) 그 화면에서 버튼을 눌렀을 때 실제로 펼쳐질 문항 수와 정확히 같은 값을 보여준다(showQuiz로 가려져 있던 문항 배열 계산을 showQuiz와 무관하게 항상 계산하도록 살짝 리팩터링해서, 버튼을 누르기 전에도 개수를 알 수 있게 함).
- 홈에서 "여러 시험 선택"으로 시험을 중복 선택해 문제를 합쳐 풀 수 있음. `HomePage.jsx`의 이 combined 퀴즈는 `getQuestionsByExams()`(유형별 기본 문제만, `questions/`)만 쓰고 `questions-extra/`는 안 가져온다 — 1차가 `questions-extra/`뿐이던 시절에는 1차 몫이 안 보였지만, 1차도 `questions/`로 완전히 이관된 뒤로는(§2) 아무것도 선택 안 해도 기본 "예제 문제 풀어보기"에 두 시험 문항(341+73=414개)이 함께 잡힌다(2026-07-29 확인).
- 유형(topic)의 `concepts` 배열 항목은 문자열(기존 방식) 또는 `ContentBlocks` 블록 배열일 수 있음 — 블록 타입: `text`/`terminal`/`image`/**`table`**(신규, `{headers, rows}`로 표 렌더링, 셀에 HTML 가능). 표가 필요한 개념(OSI 7계층, IP 클래스 등)은 블록 배열로 작성.
- 과목 카드 순서는 `content/.../<subjectId>/_meta.json`의 `"order"` 숫자 필드로 정의(작은 값이 먼저, 없으면 맨 뒤). `loader.js`의 `buildTree()`에서 정렬.

### 문제 풀이 UI (QuizPanel + QuestionCard)
- 카드박스 하나 안에 **"문제1", "문제2"…** 순서로 나열 (초기의 개별 뒤집기 카드/그리드/스와이퍼 방식은 폐기하고 이 방식으로 통일).
- "설명 보기"를 누르면 카드가 뒤집히는 게 아니라 **문제 바로 아래로 정답·해설이 펼쳐짐** (문제별 독립적으로 열고 닫힘).
- 출제율 필터(전체/1%+/3%+/5%+/10%+), "섞어서 풀기" 토글 유지.
- **차수 필터(전체/1차/2차, 2026-07-29 추가, 현재는 사실상 미사용)**: `QuizPanel`이 문제 목록 안에 `examStage`("1차"/"2차") 값이 두 종류 섞여 있을 때만 필터 버튼을 보여주는 기능. `lib/quizFilters.js`의 `getExamStage()`는 `examStage` 필드가 없는 문항을 기본값 "2차"로 취급한다. 원래는 "리눅스마스터2급" 한 시험 안에 1차/2차 문항이 섞여 있던 시절(1차가 `questions-extra/`뿐이던 때) 쓰던 필터인데, 그 후 (a) 시험 자체를 examId 기준으로 완전히 분리하고, (b) 1차 문항도 `questions/`로 이관하면서 `examStage` 필드를 아예 안 붙이게 되어, 지금은 모든 화면에서 항상 단일 값("2차" 기본값)만 존재해 필터가 절대 나타나지 않는다. 코드는 남아있지만(제거해도 무해) 사실상 죽은 기능.
- 각 문항 위에 시험명 칩(파스텔 색, 시험명 해시로 자동 색 배정) + 유형 태그 칩 표시.

### 가상 모의고사 (MockExamPage) — 3가지 모드
1. **풀고 채점하기**: 다 풀고 "채점하기" 눌러야 정답 공개.
2. **해설을 보면서 풀기**: 보기 클릭 즉시 그 문제 정답·해설 공개.
3. **실전처럼 풀기**: 회차 선택(현재는 시험별로 라운드가 1개뿐이라 버튼 하나만 뜸 — 1차 exam은 50문항·60분·과락 없음·32/18 배분, 2차 exam은 80문항·100분·과목별 과락·48/32 배분) → 타이머 시작 → 문제 전체에 **1~N 연속 번호** 부여 → 제출 시 일괄 채점 → 결과가 자동으로 **"기록"**(브라우저 로컬 저장)에 쌓여 나중에 응시 이력(일시·문항수·평균·합격여부) 조회 가능. 타이머는 화면 세로 중앙, 문제 섹션 오른쪽에 고정 표시.
   - 시험이 분리(§2)되기 전에는 "리눅스마스터2급" 한 시험 안에서 1차/2차 두 회차 중 고르는 방식이었지만, 지금은 시험 자체가 나뉘어서 각 exam의 `_rules.json`에 라운드가 1개씩만 있다(`getExamRounds()`가 여전히 배열을 반환하므로 코드 변경 없이 자연스럽게 버튼이 1개로 줄어듦).
   - 1차 배분(32/18)과 2차 배분(48/32)은 공식 공고로 확정된 값이 아니라, 사용자 판단 및 실측 기출 분석을 바탕으로 한 추정치 (각 시험 `_rules.json`의 `_comment`에 명시).

### 실제 기출 다시 풀기 (RealExamsPage / RealExamAnswerSheetPage)
- 2차 4개 회차를 목록에서 선택 → 답을 고르고 채점 → 틀린 문제 번호만 표시. 실제 PDF도 별도로 열람 가능.
- 2025-07-27부터 문항 원문·보기·해설 데이터(`src/data/realexams-full/`, gitignore 처리·로컬 전용)를 추가해 답안지에 실제 문제 텍스트를 함께 보여주고, 채점 후 "설명 보기"로 해설도 볼 수 있게 됨. 원본 PDF(해설집)에서 컬럼 분리 파싱으로 문제·보기를 추출하고, 해설은 원본의 크라우드소싱 텍스트를 그대로 옮기지 않고 정답 기준으로 새로 작성함.
  - 4개 회차 320문항 전체 원문·해설 복원 완료(2026-07-29). 절반은 텍스트로만 되어 있어 파싱으로 바로 추출됐고, 나머지 절반(문항 안에 래스터 이미지 박스로 시나리오·명령어·출력 결과가 들어있던 것)은 PDF 페이지를 이미지로 렌더링해서 직접 읽고 옮겨 적는 방식으로 전부 수작업 복원함. `pending` 필드는 이제 어떤 문항에도 남아있지 않음.
  - `realexams/`(정답 번호만, 커밋 가능)와 `realexams-full/`(원문+해설, 로컬 전용)는 별개 디렉터리로 유지 — 저작권 있는 원본 PDF와 같은 이유로 후자만 gitignore 처리됨.
- 1차는 확보한 PDF가 여러 출처를 모은 100문항 이상의 비공식 컴필레이션이라 공식 회차 구분이 없어, 이 "답안지 다시풀기" 방식은 적용하지 않고 PDF 원문 보관 + 원본 창작 연습문제 확충으로 대체함.

## 4. 알려진 제한/추정치 (재확인 필요 표시된 부분)

- 합격 기준(과목별 40점, 평균 60점 등), 1차/2차 시간·문항수, 1차 과락 없음 여부 — 공식 공고 원문 대조 필요(현재는 일반적 자격증 패턴 + 사용자 확인 기반 추정).
- 유형별 연습문제 수가 아직 실제 출제 비중만큼 채워지지 않은 유형 존재(예: 압축과 아카이브, 파일 및 디렉터리 권한 관리 등은 기본 문제가 2개뿐).
